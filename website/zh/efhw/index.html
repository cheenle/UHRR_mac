🔑 关键结论速览

  • 方案选择：T200-2 铁粉芯（μi=10）做 LC 并联谐振，效率 90–96%； 传统 49:1 宽带（FT240-43）在 10m 仅约 55%。10m 段实测增益差 +2.2 dB （等效发射功率 55W → 92W）。
  • 代价：高 Q 导致 -3dB 带宽仅 50–80 kHz → 6:1 减速旋钮是刚需。
  • 电压：高 Q 谐振把电压放大 3–5 倍；100W 时槽路峰值可达 约 3000 V → 空气可变电容耐压 ≥2000 V（400W 需 ≥4000 V）。
  • 测量基准面：best_swr 是 ATR1000 / 电台侧 的 SWR， 不是电容电压、也不是 ATU 输出端 SWR —— 它优化的是"电台透过馈线看到的东西"。
  • 控制闭环：每次伺服动作都要等一次新的 swr_update； 网络抖动、MRRC 轮询与仪表延迟直接决定扫描时长与曲线质量。
  • 安全边界：过功率 / 无 RF / 高 SWR / 超时都会中止；但电弧、槽路发热、 伺服位置与电流、进水、高压应力仍无法直接感知。

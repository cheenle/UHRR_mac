V6.1.16 · 一键升级 & 一键诊断 & 公开答复

一键升级

发现新版本后自动后台下载并校验 SHA256，点一下（页面【立即升级】或启动器窗口按 U） 即静默安装并自动重启——只弹一次管理员确认，支持一键回退上一版。 已在真机端到端验证；能热修的修复重启即生效、无需重装。

🐞 一键诊断包

菜单「🐞 遇到问题」一键生成：日志尾部 + 脱敏配置 + 环境快照 + 自动体检摘要（启动次数与时间跨度、音频健康、IOLoop 看门狗、发射初始化耗时、 天调数据新鲜度）。用户库、证书、密钥永不打包；只有你点上传才会发送。

AI 分诊 + 公开答复页

上报后自动分诊：取出诊断包生成摘要、交由项目 AI 按固定判定纪律分析， 结论以「编号 / 症状 / 诊断（附证据）/ 结论 / 你要做的」发布到 公开答复页——按编号或关键词就能搜到，多数问题自己就能解决。

TX AudioWorklet 采集

发射采集跑在 AudioWorklet 线程（960 样本 / 20ms 一帧），主线程不再被音频回调拖住； iOS/旧浏览器自动降级到 ScriptProcessor，两条路径都保持可用。

干净 RX 音频

RX 侧用毫秒水位线缓冲（桌面安全值 prebuffer 200ms / recovery 80ms / max 600ms）， 发射切换 RX 时短暂降水位换取低延迟，200ms 后自动恢复；配合 WDSP NR2 降噪与 AGC。

ATR-1000 + AGC/RF 增益

ATR-1000 实时功率/SWR 遥测与天调学习（可选组件，未接时不启动代理不轮询）； 移动端快捷栏提供 IC-M710 的 AGC 与 9 档 RF 增益（rigctld L AGC / L RF）。

核心功能

为现代 HAM Radio 打造

超低延迟

TX ~65ms / RX ~51ms，<100ms TX↔RX 切换。Opus 28kbps 编码，AudioWorklet 播放，Int16 传输 — 专业级实时体验。

  • Opus 编码 · AudioWorklet 管线
  • TX↔RX 切换低于 100ms
  • Int16 无损传输选项

WDSP 专业降噪

OpenHPSDR WDSP 库：NR2 频谱降噪 15-20dB，AGC（4 种模式），ANF 自动陷波，NB 脉冲抑制 — SSB 专项优化。

  • NR2 频谱降噪 15-20dB
  • AGC 4 模式 · ANF · NB
  • SSB 专项 DSP 管线

AI 语音助手

Whisper ASR + Qwen3-TTS：语音接收转文字、文字合成语音发射，呼号自动字母解释法转换。

  • Whisper ASR 接收 → 文字
  • Qwen3 TTS 文字 → 发射语音
  • 自动字母解释法转换

三层 PTT 安全防护

释放 ACK 协议含 3 次重试 + 冗余音频通路回退，120s TOT 硬限制，触屏滑动自动释放，页面隐藏强制停发 — 杜绝电台卡发射。

  • ACK × 3 次重试 + 音频回退
  • 120s TOT 硬限制
  • 滑动/隐藏强制停止

ATR-1000 + RagChew 音频

ATR-1000：0-200W 实时功率显示，SWR 1.0-9.99，频率→天调参数智能学习。RagChew TX 链路：低切 150Hz，临场 +3dB@2.4kHz，3:1 压缩器，-50dB 噪声门。

  • ATR-1000：功率/SWR/天调学习
  • RagChew：EQ + 压缩器 + 噪声门
  • MemoryChannelManager · LearningBuffer

开始使用

5 分钟搭建

连接电台

CAT 串口 + 音频线连接到电脑。MRRC 通过 Hamlib 自动检测

rigctld -m 2 -r /dev/ttyUSB0 -s 38400

安装 MRRC

克隆仓库 — MRRC 即拉即用，无需安装脚本

git clone https://github.com/cheenle/UHRR_mac && cd UHRR_mac

启动服务器

启动服务栈 — rigctld、MRRC（TLS + WebSocket + 音频）和 ATR-1000 代理

./mrrc_control.sh start

打开浏览器

同一网络内的任意设备 — 手机、平板或电脑

https://电台主机:8877/mobile_modern.html
Windows 安装包下载 安装指南

已经装过（V6.1.0 及以后）？不用再下载 —— 打开应用 → 菜单 ⬆️ 软件更新（或在启动器窗口输入 U 回车）：它会自己下载、校验、静默安装并重启。 V6.0.10 及更早没有升级功能，装一次本安装包即可启用。 遇到问题先看 公开答复页（按上报编号搜索）。

产品支持闭环：发版 → 一键升级 → 🐞 一键诊断包 → AI 分诊 → 公开答复页。详见 功能页 → 产品支持生命周期（完整五段表见 产品支持生命周期）。

核心功能

为现代 HAM Radio 打造

超低延迟

TX ~65ms / RX ~51ms，<100ms TX↔RX 切换。Opus 28kbps 编码，AudioWorklet 播放，Int16 传输 — 专业级实时体验。

  • Opus 编码 · AudioWorklet 管线
  • TX↔RX 切换低于 100ms
  • Int16 无损传输选项

WDSP 专业降噪

OpenHPSDR WDSP 库：NR2 频谱降噪 15-20dB，AGC（4 种模式），ANF 自动陷波，NB 脉冲抑制 — SSB 专项优化。

  • NR2 频谱降噪 15-20dB
  • AGC 4 模式 · ANF · NB
  • SSB 专项 DSP 管线

AI 语音助手

Whisper ASR + Qwen3-TTS：语音接收转文字、文字合成语音发射，呼号自动字母解释法转换。

  • Whisper ASR 接收 → 文字
  • Qwen3 TTS 文字 → 发射语音
  • 自动字母解释法转换

CW + FT8 数字模式

浏览器端 AI CW 解码（<2MB ONNX，<50ms）。FT8 ULTRON 控制台：JTDX/WSJT-X/MSHV 全兼容，实时瀑布图，自动序列器，DXCC 追踪。

  • ONNX AI CW 解码 · QSO 状态机
  • FT8 ULTRON: JTDX/WSJT-X/MSHV 桥接
  • 自动序列器 · DXCC 追踪

三层 PTT 安全防护

释放 ACK 协议含 3 次重试 + 冗余音频通路回退，120s TOT 硬限制，触屏滑动自动释放，页面隐藏强制停发 — 杜绝电台卡发射。

  • ACK × 3 次重试 + 音频回退
  • 120s TOT 硬限制
  • 滑动/隐藏强制停止

ATR-1000 + RagChew 音频

ATR-1000：0-200W 实时功率显示，SWR 1.0-9.99，频率→天调参数智能学习。RagChew TX 链路：低切 150Hz，临场 +3dB@2.4kHz，3:1 压缩器，-50dB 噪声门。

  • ATR-1000：功率/SWR/天调学习
  • RagChew：EQ + 压缩器 + 噪声门
  • MemoryChannelManager · LearningBuffer

开始使用

5 分钟搭建

连接电台

CAT 串口 + 音频线连接到电脑。MRRC 通过 Hamlib 自动检测

rigctld -m 2 -r /dev/ttyUSB0 -s 38400

安装 MRRC

克隆仓库并运行安装脚本

git clone https://github.com/cheenle/UHRR_mac && cd UHRR_mac && ./install.sh

启动服务器

启动 Python 后端 — TLS、WebSocket 和音频管线集成在单进程中

python3 server.py --port 8877

打开浏览器

同一网络内的任意设备 — 手机、平板或电脑

https://电台主机:8877/mobile_modern.html

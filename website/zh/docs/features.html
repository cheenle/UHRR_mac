🔧 WDSP专业降噪处理

集成Warren Pratt's Digital Signal Processing库，这是OpenHPSDR项目的高性能DSP库，广泛应用于Thetis、piHPSDR等专业业余无线电软件。

核心功能

🔇

NR2 频谱降噪

基于谱减法的降噪算法，15-20dB降噪深度，语音保真度极高，专门针对SSB语音优化

⚡

NB 噪声抑制

消除脉冲干扰，有效抑制电器火花、雷电等突发噪声

🎯

ANF 自动陷波

自动消除单频干扰，适用于CW报音、载波干扰等场景

📊

AGC 自动增益

4种模式可选：LONG/SLOW/MED/FAST，适应不同信号环境

🛡️ PTT 安全防护系统 (V5.6+)

三层 TX 保护架构，专门防止远程电台操控中最危险的故障模式：电台卡在发射状态。每层提供独立保护，并具有冗余回退路径。

第一层：客户端守护 (浏览器)

👆

触屏滑动自动释放

手指滑出发射按钮 → 通过 touchmove/touchcancel 立即停止 PTT

🪟

页面隐藏强制停发

页面进入后台或窗口失焦且 TX 激活中 → 强制释放 PTT，最多防止 30 秒意外发射

⏱️

30 秒看门狗定时器

硬件看门狗：TX 状态激活超过 30 秒且无确认 → 强制释放

🔒

处理锁泄漏检测

处理锁持有超过 3 秒 → 自动释放，防止静默停发失败导致 TX 卡死

第二层：释放 ACK 协议

机制描述
ACK 重试发送 setPTT:false 后，等待最多 1 秒服务端确认。若未确认，最多重传 3 次
冗余音频通路回退每次重试时，同时通过 TX 音频 WebSocket 发送 s: 作为冗余释放路径 — 即使控制 WebSocket 半开也能工作
连接断开触发3 次 ACK 重试失败后，强制通过 onControlConnectionDead() 重建控制通道

第三层：服务端保护

机制描述
120 秒 TOT 硬限制超时定时器：PTTSafetyMonitor 线程强制执行绝对 120 秒最大发射时长
持续重试PTT 释放每 2 秒重试一次，直到硬件确认状态变化
故障广播pttError:release_failed 或 pttError:tot_timeout 广播给所有连接的客户端

⬆️ 一键升级（Windows 安装版）

自 V6.1.0 起内建，V6.1.15 真机端到端验证通过。启动器启动时读取 SHA256 固定校验的清单，发现新版本就在后台下载（不打断收听），然后等你触发：

  • 页面 → 菜单 → ⬆️ 软件更新 → 【立即升级】，或
  • 启动器窗口 → 输入 U 回车。

随后：弹一次管理员确认（UAC）→ 静默安装 → 自动重启到新版本。新版启动时自己确认成功， 所以“到底成功没有”是事实而不是猜测；上一版保留在服务器上，【回退到上一版】同样一键。

为什么在 Windows 上不简单

控制台程序没有消息循环（安装器的 RestartManager 关不掉它）、已提权进程再用 runas 启动会在非交互窗口站永久卡住、控制台代码页是 GBK（日志里的 emoji 会杀死转发线程）、 threading.Lock 只在进程内有效（两个启动器实例会抢同一个临时文件）。 这十类陷阱都由真机验收抓出并修复。

🐞 一键诊断包

出问题时用户不必看懂日志：菜单 → 🐞 遇到问题 一键收集维护者真正需要的东西—— 启动器/服务端输出、state.json、安装器日志、音频设备表、性能采样、以及 脱敏后的配置（白名单；密钥替换；证书与用户数据库永不打包）， 并附带自动体检摘要（IOLoop 看门狗、发射初始化耗时、音频健康、天调数据新鲜度）。 可一键上传给维护者，也可只保存到本地。

🎛️ 电台机型表与 hamlib 实时对齐

设备配置不再硬编码机型：rig_models.py 运行时枚举本机 hamlib 的 312 个机型，并同时写入协议栈真正读取的两个键 （[HAMLIB] rig_model 与 [INSTANCE_SETTINGS] instance_rigctl_model）， 与 rigctld 实报不一致时在界面上给出提示。

🛟 产品支持生命周期

MRRC 是当作产品维护的：发版 → 升级 → 诊断 → AI 分诊 → 答复 形成闭环，最后一步你可以自己看。 完整的五段表（做法 / 判据 / 产物 / 细则链接）见 产品支持生命周期：

发版单测 + 内联脚本语法守卫 + 产物级热修验收 3/3 三道闸门；站点维护 latest.json（升级）与 patch.json（热修）；发布字节以服务器侧 SHA256 为准
升级一键（页面按钮或按 U）→ 下载 + 校验 → 一次 UAC → 静默安装 → 自动重启；成功判据 = 新版自证 lastResult = ok
诊断🐞 一键生成脱敏诊断包（含自动体检摘要）
AI 分诊定时任务取出新上报、生成摘要，交由项目 AI 按固定判定纪律分析（材料不足就写“需要补充信息”，绝不下没有证据的结论）
答复结论发布到 公开答复页（按编号/关键词可搜）；确认是缺陷时：先给临时规避，再修代码——能热修的重启即生效

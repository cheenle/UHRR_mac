🎛️ WDSP 数字信号处理

WDSP (Warren Pratt's Digital Signal Processing) 是 OpenHPSDR 项目开发的高性能DSP库，被广泛应用于专业业余无线电软件。

功能模块

模块 功能 效果
NR2 频谱降噪 15-20dB 降噪深度
NB 脉冲噪声抑制 消除火花/雷电
ANF 自动陷波 消除单频干扰
AGC 自动增益控制 4种模式可选

AGC 模式

  • LONG：长延迟，适合稳定信号
  • SLOW：慢响应，平衡选择
  • MED：中等响应，默认推荐
  • FAST：快速响应，适合快速QSY

📊 ATR-1000 集成

系统架构

智能天调学习

  • 自动学习：每次发射时记录频率与天调参数对应关系
  • 快速调谐：频率变化时自动应用已学习参数
  • 参数持久化：保存到 atr1000_tuner.json

📝 通信协议

WebSocket 命令 (WSCTRX)

命令格式说明
设置频率setFreq:14074000Hz 为单位，同步至 ATR-1000
读取频率getFreq从电台读取，广播响应
设置模式setMode:USBUSB/LSB/CW/FM/AM
读取模式getMode从电台读取当前模式
PTT 发射setPTT:true按下发射键（含重试）
PTT 接收setPTT:false释放发射键（含 ACK 协议，3 次重试）
读取 PTTgetPTT从硬件读取实际 PTT 状态
调谐音tune:true / tune:false启动/停止调谐音 (5% 音量)
CQ 播放cq:true / cq:false启动/停止 CQ 音频 (cq.wav)
WDSP 开关setWDSPEnabled:true启用/禁用 WDSP 处理
NR2 级别setWDSPNR2Level:20=关, 1=低, 2=中, 3=高, 4=最高
噪声消除setWDSPNB:true开关 NB (脉冲干扰)
自动陷波setWDSPANF:true开关 ANF 自动陷波滤波器
添加陷波addWDSPNotch:1500,200手动陷波 (中心频率Hz, 宽度Hz)
AGC 模式setWDSPAGC:30=关, 1=长, 2=慢, 3=中, 4=快
带通滤波setWDSPBandpass:300,2700低截止 Hz, 高截止 Hz
录音startRecording / stopRecording立体声 WAV → MP3 录音
频道存储memLoadAll / memSaveAll:{json}每用户记忆频道 (6 个槽位)
心跳PING延迟检测，响应 PONG

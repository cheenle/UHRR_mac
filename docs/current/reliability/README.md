# 可靠性案例索引（Reliability & Safety Cases）

## 使用约定

- 新案例按 `RC-NNN-short-title.md` 命名，编号递增。
- 每份案例必须包含"验证方法"章节：只写进了哪些日志/测量数据、如何解读，不写无法复现的推断。
- 修复状态必须关联 CHANGELOG 版本号。
- 关联代码注释中的 fix 标记（F2/F3/F4/F4b…）与本目录案例互相引用。

## 横向主题

多个案例反复出现的根因模式，单独汇总在各自案例的"经验教训"章节；当出现 ≥3 次同类模式时应提取为独立的最佳实践文档。

## 2. 谐振结构与物理参数

### 2.1 f1 = 6.50 MHz 的实测证据链

1. SWR=1.00 平台宽 160 kHz（6.42–6.58，17 连续点，9–10W 前向功率下稳定）；
2. 两翼斜率对称平滑（左侧 6.0M=3.38→6.41=1.35，右侧 6.59=1.16→7.0=2.87→7.3=4.5）；
3. **功率互证**：谐振平台上电台实际出力 9–10W，失配区跌到 5W（40m）/2W（10m）——
   ALC 对失配的回退行为与 SWR 曲线互为镜像，两套独立测量互相印证；
4. 跨场次互验：7.000MHz 在加密扫描（2.83）与全段扫描（2.87）中一致。

### 2.2 49:1 裁决——实测终局

bypass 状态在 f1 平台测得 SWR=1.00，即"UNUN+馈线"链在谐振点把线端阻抗正好
变到 50Ω 附近。**49:1 对这条天线是正中靶心的变比**，不是妥协项。
（早前 LC 反演估线端 1350–1650Ω 偏低，是因外推跨度大；以 bypass 实测为准，
线端 R_res ≈ 2200–2700Ω，贴近教科书 2450Ω。）

### 2.3 谐波比上漂

1 : 2.15 : 3.28 : 4.38——高次谐波逐级高于整数倍，EFHW 末端效应（端电容）
在基波时缩短电气长度最多、高频时影响占比下降的典型表现。这也意味着：
**f1 压低在 6.5 反而把 3f 送进了 15m 正中、2f 送到 20m 下沿**——当前线长
对高波段是意外优化，对 40m 是固有惩罚。

### 2.4 Q 与带宽

f1 区 SWR≤2 带宽 530kHz → **Q≈12**，对架空斜拉 EFHW 属正常偏宽
（近地损耗+馈线参与降低了 Q，换来的正是 15m 的宽平台）。

## 3. 天调参数现状（学习库）

- 实测锚点 34 条 + 拟合填充 270 条（`source:"fit"`，零样本，`needs_verify`，
  被真实学习自然覆盖，偏差大时 SWR 守卫自愈）；
- 40m 典型：LC L=0.7–1.2µH / C=440–480pF（7050 锚点 n=1075，最可靠）；
- 20m：CL L=0.4–0.6µH / C=110–170pF；15m：LC L≈0–0.1µH / C=20–40pF（近乎直通）；
- 30m/12m 无锚点未填充；80m 放弃。
- **雨致失谐**（交叉报告实测）：降雨时 7050 需 L 0.6→1.5µH 增量补偿；
  雨后可重跑单段扫频对比基线漂移。

## 4. 辐射特性（PSK Reporter 7 天裸数据交叉）

- **典型仰角 9–12°**——斜拉 EFHW 的低仰角 DX 特性成立；
- **方位**：下坡方向（西南 ~220°，振子低端指向）实测 SNR 均值最强，
  与斜拉天线"辐射偏向下坡/低端方向"的理论一致；
- 详见姊妹篇的方位×距离×SNR 交叉表。

## 5. 损耗与功率

- 天调匹配网络低 Q（0.6–0.8），本体损耗 <0.05dB，可忽略；
- 100W 时馈点电压 ≈ **495 Vrms / 700 V peak**（R_res≈2450Ω）——UNUN 次级
  绝缘按 ≥700V 峰值设计（website/efhw 巴伦专题告诫一致）；
- 80m 若硬用：裸 SWR 16 → 馈线附加损耗 3–6dB，一半以上功率热在馈线里。

## 7. 行动建议

1. **维持线长**：裁线抬 f1 进 40m 会毁掉 15m 的完美平台和 20m 下沿，得不偿失；
2. **80m 彻底放弃**在现系统上调谐；要 80m 就架专用天线；
3. **日常用段优先级**：15m > 20m（下半段）> 40m（天调）> 10m（中段）；
   避开 17m/30m/12m；
4. **雨季运维**：降雨天后用扫频页单扫 40m（2 分钟）对比基线，漂移即自动重学；
5. **馈点端验证**（待办）：NanoVNA 在 UNUN 端扫 1–30MHz，独立标定馈线电气长度。
